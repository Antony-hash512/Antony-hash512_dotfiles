🪟+Q или Ctrl+Alt+Tзапуск нового окна терминала

Полезные комбинации клавиш терминала:

комбинациярезультат
Enterвыполнить введённую команду
Ctrl+Cпрервать текущую не завершённую команду
Ctrl+Lочистить экран
Ctrl+Uстереть введённую строку
Ctrl+DБайт-код конца файла, например для выхода из python. Если никакая команда в этот момент не испольняется это приведёт к закрытию терминала.
Tabавтодополнение команд и путей
↑↓просмотр истории команд
Ctrl+Shift+Cкопировать выделенный текст
Ctrl+Shift+Vвставить скопированный текст

Основные обозначения:

.текущая директория
..родительская директория (выше на один уровень по иерархии)
~домашняя директория (обычно /home/имя_пользователя)
/корневая директория установки системы

Примеры интересных команд:

команда
результат
fastfetch
показать информацию о системе с логотипом в виде ASCII-арта
cowsay <текст>
показать текст в виде ASCII-арта коровы
figlet <текст>
показать текст в виде ASCII-арта больших букв

Основные команды терминала для начинающих:

команда
результат
man <команда>
показать руководство по команде (выход: q)
man kitty
как пример, руководство по эмулятору терминала kitty
ls
показать содержимое текущей директории
ls -l
показать содержимое текущей директории в длинном формате
ls -a
показать все файлы, включая скрытые
ls -la
показать все файлы, включая скрытые, в длинном формате
cd <директория>
перейти в указанную директорию
mc
двухпанельный файловый менеджер Midnight Commander (выход: f10)
htop
системный монитор (выход: f10)
btop
альтернативный системный монитор (выход: q)
ping google.com
проверить доступность интернета (выход: Ctrl+C)
wget <интернет-ссылка>
скачать файл из интернета
curl <интернет-ссылка>
скачать файл из интернета
curl -O <интернет-ссылка>
скачать файл из интернета и сохранить с оригинальным названием
mkdir <имя>
создать новую директорию
mkdir -p <путь>
создать директорию по указанному пути, не выдавая ошибку, если она уже существует; если нет промежуточных директорий, то создать их
rm <файл>
удалить файл
rmdir <директория>
удалить директорию (если она пустая)
rm -r <директория>
удалить директорию и всё её содержимое
cp <источник> <назначение>
копировать файл
mv <источник> <назначение>
переместить/переименовать файл
touch <файл>
создать пустой файл
echo "<текст>" >> <файл>
дописать текст в конец текстового файла
echo "<текст>" > <файл>
полностью перезаписать текстовый файл
cat <файл>
показать содержимое файла
bat <файл>
показать содержимое файла в красивом формате
nano <файл>
открыть текстовый редактор (выход: Ctrl+X, Y, Enter)
vim <файл>
продвинутый текстовый редактор для программистов или опытных пользователей (выход: :q)
xed <файл>
открыть файл в графическом текстовом редакторе
<команда> &
запустить команду в фоновом режиме (например: xed &)
lsblk
показать схему устройств ПЗУ и разделов на них
tar -cf <архив> <файлы>
создать архив
tar -xvf <архив>
распаковать архив
tar -czf <архив>.tar.gz <файлы>
создать сжатый tar.gz архив
tar -xzf <архив>.tar.gz
распаковать tar.gz архив
tar -tzf <архив>.tar.gz
просмотреть содержимое tar.gz архива без распаковки
7z a <архив> <файлы>
создать архив с помощью 7-zip
7z x <архив>
распаковать архив с помощью 7-zip
7z a --mx=9 <архив> <файлы>
создать архив с максимальным сжатием с помощью 7-zip (если объём данных большой, рекомендуется выйти из графического интерфейса и/или включить скорость вентилятора на максимум перед выполнением этой команды)
tar cf - <директория> | 7z a -si имя_архива.tar.7z
создать архив tar.7z, который поддерживает атребуты файловов
cat /etc/shells
посмотреть список оболочек, установленных в системе
chsh -s <путь к оболочке>
Сменить оболочку, которая будет использоваться по умолчанию после следующего входа в систему.
fastfetch
показать информацию о системе
history
показать историю команд
!<номер команды>
ввод команды из истории по номеру
clear
очистить экран терминала
tree
показать структуру директорий
pwd
показать текущий путь
links
текстовый веб-браузер (g - открыть адресную строку, q - выход)
chmod +x <файл>
сделать файл исполняемым
ln -s <источник> <назначение>
создать символическую ссылку
ln -T <источник> <назначение>
создать жесткую ссылку
pkill <программа>
завершить процесс по его названию
kill -9 <PID>
завершить процесс по его PID
killall <программа>
завершить все процессы по его названию
grep <текст> <файл>
найти текст в файле
df -h
показать свободное место на дисках
reboot
перезагрузить компьютер
poweroff
выключить компьютер
shutdown now
выключить компьютер
sudo <команда>
выполнить команду с правами администратора
sudo pacman -Syu
обновить список пакетов и систему
sudo pacman -S <пакет>
установить программу из официальных репозиториев
pacman -Ss <пакет>
найти описание пакета в репозиториях
paru -S <пакет>
установить программу из AUR (пользовательский репозиторий Arch Linux)
paru -Ss <пакет>
найти описание пакета в AUR
sudo lshw
показать информацию о железе
