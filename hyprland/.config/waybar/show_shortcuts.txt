Основные сочетания клавиш:
- 🪟: Меню выбора софта для запуска (запускается при отпускании клавиши, если не было нажато другое сочетание с 🪟)

- 🪟 + H: Эта справка по горячим клавишам
- 🪟 + T: Справка по основным командам терминала

- 🪟 + Q: Эмулятор терминала командной строки
- 🪟 + W: Интернет-браузер
- 🪟 + E: Файловый менеджер
- 🪟 + R: Запуск произвольной команды вне терминала
- 🪟 + N: Запустить синтезатор речи для озвучки из буфера обмена
- 🪟 + B: Открыть настройка Bluetooth
- PrintScreen: Открыть диалоговое окно для создания скриншота, в котором можно задать различные параметры
- 🪟 + C или Alt + F4: Закрыть активное окно
- 🪟 + M: Завершение работы (выбор между: блокировка/выход/ожидание/сон/выключение/перезагрузка)
- 🪟 + L: Быстрая блокировка рабочего стола
- 🪟 + Стрелки: Переключение между окнами внутри рабочего стола
- 🪟 + Левая кнопка мыши: Перемещение окна
- 🪟 + Правая кнопка мыши: Изменение размера окна
- 🪟 + Ctrl + Стрелка: Изменение размера окна при помощи клавитуры
- 🪟 + Колесо мыши: Передвижение между уже открытыми рабочими столами
- 🪟 + Цифра: Переход на другой рабочий стол
- 🪟 + Shift + Цифра: Перемещение окна на другой рабочий стол
- 🪟 + Пробел или Alt + Shift : Переключение раскладки клавиатуры (языка)
- Ctrl + C: Копировать выделенный текст в графической среде или завершить процесс в терминале
- Ctrl + Shift + C: Копировать выделенный текст из терминала
- Ctrl + V: Вставить скопированный текст в графической среде
- Ctrl + Shift + V: Вставить в терминале
- 🪟 + J: Переключение между горизонтальным и вертикальным расположением окон
- 🪟 + V: Переключение между тайловым и плавающим расположением окна
- 🪟 + Shift + Стрелка: Перемещение плавающего окна при помощи клавиатуры
- 🪟 + Alt + Стрелка: Перемещение тайлового окна при помощи клавиатуры
- Fn + 🔇: Включение/Выключение звука
- Fn + 🔉: Уменьшение громкости звука
- Fn + 🔊: Увеличение громкости звука
- Fn + 🌙: Уменьшение яркости экрана
- Fn + ☀️: Увеличение яркости экрана
- F11: Полноэкранный режим в браузере firefox
- Alt + Цифра: Переключение между вкладками в firefox (и многих других графических программах)
